## Default Permission

Confirm accepted gestures with native haptic feedback.

#### This default permission set includes the following:

- `allow-haptic`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`ios-feedback:allow-haptic`

</td>
<td>

</td>
</tr>

<tr>
<td>

`ios-feedback:deny-haptic`

</td>

</td>
</tr>
