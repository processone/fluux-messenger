## Default Permission

Hand a local file to the system share sheet, to save or send it elsewhere.

#### This default permission set includes the following:

- `allow-share-file`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`share-sheet:allow-share-file`

</td>
<td>

</td>
</tr>

<tr>
<td>

</td>
